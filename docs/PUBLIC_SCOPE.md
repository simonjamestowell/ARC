# Public Scope

This repository is public by design, but it is not the full private build.

## Public

- method summary
- public scorecard links
- community leaderboard submission files
- high-level automation interfaces

## Private

- full implementation
- runtime internals
- internal orchestration code
- solver internals not needed for public method description

## Why This Boundary Exists

The ARC Prize community leaderboard requires a public `code_url`. That is not
the same thing as a full independent rebuild and verification of the private
system. This repository therefore provides an honest public-facing package of
materials around the verified public scorecards.
